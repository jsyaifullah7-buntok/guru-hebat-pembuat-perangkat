SELAMAT DATANG DI APLIKASI GURU HEBAT

PEMBUAT PERANGKAT PEMBELAJARAN

Rancang, kembangkan, validasi, dan siapkan perangkat pembelajaran dalam satu alur yang sederhana, konsisten, dan mudah digunakan.

📝

Input Data

Masukkan identitas guru, sekolah, materi, submateri, TP, alokasi waktu, fasilitas, dan data kepala sekolah.

📘

Perangkat Pembelajaran

Bangun Modul Ajar/RPP, Bahan Ajar, LKPD, serta Kisi-kisi dan Soal dari data pembelajaran yang sama.

🖥️

MPI Interaktif

Siapkan media pembelajaran interaktif HTML yang responsif untuk HP, tablet, laptop, dan PID.

🔎

Sumber Resmi

Prompt memprioritaskan regulasi dan sumber resmi Kemendikdasmen, Rumah Pendidikan, Ruang GTK, SIBI, serta sumber pendukung yang relevan.

🔗

Satu Ekosistem

IDENTITAS → CP → TP → ATP → MATERI → KEGIATAN → ASESMEN → BAHAN AJAR → LKPD → SOAL → MPI.

⚡

Eksekusi Langsung

Master Prompt memerintahkan AI untuk mengeksekusi hasil tanpa bertanya kembali dan tetap menjaga validasi sumber.

Catatan: Pada mode offline, aplikasi tidak mengklaim melakukan sinkronisasi sumber secara live. Prompt OpenAI membawa aturan validasi sumber agar proses online/backend dapat memeriksa sumber resmi secara nyata.

Aplikasi ini dibuat oleh Al-Faqir Syaifulah, S.Pd.I

Input Identitas & Rancangan Pembelajaran

Isi data utama. Aplikasi akan membangun perangkat pembelajaran secara otomatis berdasarkan data yang dimasukkan.

Mesin Sinkronisasi: TP tetap diinput guru. CP/ATP, materi, dan sumber belajar akan dianalisis oleh AI berdasarkan sumber resmi yang dapat diverifikasi. Pada mode offline, aplikasi tidak mengklaim melakukan sinkronisasi live; tombol Prompt OpenAI menghasilkan prompt terstruktur yang siap ditempel ke ChatGPT/OpenAI dengan instruksi verifikasi sumber.
Pencocokan CP & ATP: TP diinput manual oleh guru. Pada versi offline ini, aplikasi menampilkan status bahwa CP/ATP akan dicocokkan melalui sumber resmi saat modul online/backend diaktifkan. Aplikasi tidak mengklaim mengambil data Rumah Pendidikan secara live ketika offline.

🪄 Prompt OpenAI — Master Prompt Perangkat Pembelajaran

Prompt ini membawa seluruh identitas dan rancangan pembelajaran dari Tab Input Identitas. Salin ke ChatGPT/OpenAI untuk menghasilkan perangkat yang lebih lengkap dan tersinkron.

Prioritas sumber: regulasi terbaru → Rumah Pendidikan/Ruang GTK → CP/ATP → Sumber Belajar → katalog buku resmi/SIBI → SIAP/Puskesjar dan sumber resmi kementerian lain yang relevan. AI wajib memverifikasi sumber dan dilarang mengarang CP, ATP, buku, regulasi, atau URL.
Mode Online: memeriksa koneksi backend...
API key OpenAI disimpan hanya di backend, bukan di browser. Mesin validasi memeriksa sumber yang diizinkan sebelum AI dijalankan.
